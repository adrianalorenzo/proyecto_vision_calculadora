# AirMath 

**Write numbers in the air with your finger and let the camera do the maths.**

Final project of *Computer Vision I* (3rd year, Mathematical Engineering and AI — Comillas ICAI, 2026-27).

AirMath is a real-time computer vision system that works with the laptop webcam:

1. **Security system** — the user unlocks the app by showing four printed cards with mathematical symbols (π, √, ∞, Σ) in the right order. Cards are detected by their black frame, rectified with a homography and recognised by template matching. An **AC** card resets the sequence.
2. **Air calculator** — the hand is tracked with MediaPipe Hands (bounding box + 21 landmarks) and the index fingertip, smoothed with a Kalman filter, works as a pen. Digits are recognised with an SVM and operators (+ − × ÷) with simple stroke rules.
3. **Modes** — *Calculator*, *Mental Math* (2-minute game with statistics and records) and *Versus* (two players, same operation).

The camera is calibrated offline with a chessboard pattern, and every frame is undistorted before processing. The FPS are always shown on screen.

## Repository structure

```
proyecto_vision_calculadora/
├── src/
│   ├── test_camera.py         # reads the webcam and shows the FPS
│   ├── capture_images.py      # captures chessboard images for the calibration
│   ├── calibration.ipynb      # camera calibration + undistortion + check
│   ├── live_undistort.py      # live original | undistorted comparison
│   ├── security.py            # card detector + password decoder
│   ├── capture_templates.py   # captures the template of every card
│   ├── test_security.py       # live test of the security system
│   ├── ui.py                  # all the screens drawn with OpenCV
│   ├── test_ui.py             # screens with fake data
│   └── main.py                # the whole application
├── data/
│   ├── calibration/           # calibration images and params.npz
│   └── templates/             # card templates
├── output/                    # images and videos generated by the scripts
└── assets/                    # printable chessboard pattern and password cards
```

## Requirements

Same conda environment as the lab sessions (`voi-lab`, Python 3.9, OpenCV 4.8). Extra packages are listed in `requirements.txt`.

## How to run

All scripts are run from the `src` folder:

```bash
cd src
python test_camera.py          # check that the webcam works
python capture_images.py       # SPACE saves a chessboard image, q quits
# run calibration.ipynb from top to bottom
python live_undistort.py       # live comparison, s saves an image
python test_security.py        # live test of the password cards
python main.py                 # AirMath (q quits, r records a video)
```
